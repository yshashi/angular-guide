## Everything you need, in one place 🚀

NG Guide teaches **Angular 22** the way you would write it today: standalone components, signals,
the built-in control flow (`@if`, `@for`), Signal Forms, zoneless change detection and Vitest.
Every page explains the _why_ in plain English, then shows small, working, type-checked examples.

## Why NG Guide? 💡

- **Up to date** — written for Angular 22.2 (the latest stable release), with short notes when
  older versions behave differently.
- **Simple first** — each topic starts with the basics and builds up to real-world use.
- **Code you can trust** — examples use current best practices: `inject()`, `input()`/`output()`,
  signals, native control flow and `@Service()`.
- **One-stop** — concepts, examples, common mistakes and next steps on every page, so you rarely
  need to look anywhere else.

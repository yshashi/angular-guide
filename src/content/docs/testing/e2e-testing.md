# E2E Testing with Playwright 🎭

> **Note:** Protractor has been deprecated and removed from Angular. For new projects, use **Playwright** (recommended) or **Cypress** for end-to-end testing. The Angular CLI supports adding Playwright via `ng e2e` with third-party builders.

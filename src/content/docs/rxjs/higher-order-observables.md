Higher-order Observables emit Observables as values. Learn when to use switchMap, mergeMap, concatMap, and exhaustMap in Angular.

## 🎯 Higher-Order Mapping Operators

**The Big Four:**
- **switchMap** - Cancel previous, switch to new
- **mergeMap** - Run all concurrently
- **concatMap** - Run in sequence
- **exhaustMap** - Ignore while busy
